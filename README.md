## Project Overview
A website for **No Crusty Vibes**, a real South African premium streetwear
brand founded in 2016 by Lindokuhle Skosana ("Kasi to the World™"). The site
sells the brand's clothing range online, drives traffic to the brand's
Instagram, tells the brand story, and establishes a professional digital
presence — the brand currently has no website, only an Instagram page.

## Website Goals and Objectives
- Sell clothing online
- Drive traffic to the brand's Instagram
- Tell the "Kasi to the World" brand story
- Establish a professional digital presence
- **KPIs:** enquiry form submissions, Instagram click-throughs, time on
  Shop page, repeat visits

## Key Features and Functionality
- 5-page site: Home, About, Shop (Services), Gallery, Contact — matching
  the agreed project file structure
- Hyperlink navigation connecting every page (shared header/footer)
- Full product catalogue across t-shirts, tracksuits, outerwear, tanks,
  totes, and slides, with pricing
- Gallery page as a visual lookbook of every collection
- Enquiry form (with basic front-end validation via JavaScript) built
  into the Contact page, in place of a separate Enquiry page — see
  Deviations note below
- Contact page listing two physical locations (Johannesburg flagship +
  Cape Town stockist network)
- External stylesheet (`CSS/style.css`) applying a dark green, white, and
  gold luxury colour palette
- Fully responsive layout (desktop / tablet / mobile) using CSS Grid,
  Flexbox, and media queries

### JavaScript features
- **Gallery lightbox** (`Gallery.html`): click or press Enter on any photo to view it enlarged, with previous/next buttons, arrow keys, Esc to close.
- **Shop search and sort** (`Services.html`): live search by product name plus sort by price or name; empty sections hide automatically.
- **Dynamic content** (`Home.html`): the "Fresh drops" product cards are generated by JavaScript from a data array.
- **Accordion** (Shop FAQs) and **scroll-in animations** (CSS transitions + IntersectionObserver).
- **Interactive maps**: Google Maps embeds for the Johannesburg store and Cape Town on `Contact.html`.
- **Forms with validation and AJAX**: contact message form (`Contact.html`) and product enquiry form with instant cost estimate (`Services.html`). Validation covers name, email, SA phone format, message length (10–500), quantity range, with inline error messages. Data is sent with `fetch` (AJAX) to FormSubmit.co, which emails it to the brand; if not configured it falls back to `mailto:`.

### SEO and technical
- Unique `<title>` and meta description per page, keywords, Open Graph tags, canonical links, one `<h1>` per page with logical `h2`/`h3`, descriptive image file names and alt text, internal links in header/footer, mobile-friendly responsive layout.
- Local SEO: schema.org `ClothingStore` JSON-LD with the Kwa-Thema address (Home).
- `robots.txt` and `sitemap.xml` added in the site root.
- Page speed: lazy-loaded images, `defer` on scripts, preconnect for fonts.
- Security: Content-Security-Policy meta tag, referrer policy, `rel="noopener"` on external links, client and pattern validation, no inline scripts.

### Deviation note
The Part 3 brief mentions `enquiry.html`. To stay with the five-page structure agreed in Parts 1–2, the product enquiry form (with cost response) sits on the Shop page and the general message form on the Contact page.

## Deviations from the Assignment Brief
The brief's default sitemap calls for an `Enquiry.html` page. This project
uses **Gallery.html** in its place, matching the project file/folder
structure agreed and set up before build. The enquiry form itself has not
been dropped — it lives on the Contact page instead, so the
product/stock/partnership enquiry functionality the brief requires is
still fully present, just consolidated onto Contact rather than its own
page.
